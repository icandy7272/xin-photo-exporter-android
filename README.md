# 鑫时光集 Android 原图导出器

一个独立的、仅处理用户自己账号内容的本地导出工具。项目利用 MuMu 中已登录的“鑫时光集家长版”、ADB 和 App 自身输出的原图资源地址，将原图验证并导出到 Mac。

当前阶段只实现三个样本的原图直下验证。不会进行全量下载、URL 枚举、云端 AI 处理或账号范围之外的访问。

## 当前状态

- 技术可行性已通过只读探测验证。
- 设计规格已完成，等待独立审查和用户确认。
- 尚未实现下载工具。

## 隐私原则

- 完整原图 URL 只在运行内存中短暂存在。
- URL、照片、EXIF和账号信息不得写入 Git、普通日志或报告。
- 所有照片处理均在用户本机完成。
