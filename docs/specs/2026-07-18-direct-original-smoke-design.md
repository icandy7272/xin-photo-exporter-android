# Android 原图直下验证 MVP 设计

## 目标

从用户当前已登录的 MuMu“鑫时光集家长版”进程日志中取得三个不同的“原图地址”，将对应 JPEG 下载到隔离的本地测试目录，并验证文件完整性。最后由用户人工确认样本内容和画质。

本项目与原有 Mac/iPhone“鑫时光集照片助手”完全独立，不使用它的源码、Bundle ID、权限、构建产物或 Git 历史。

## 已验证事实

- MuMu 设备为 Android 12（API 32）、ARM64。
- 鑫时光集家长版包名为 `com.childfolio.family`，版本 `1.9.17`，target SDK 35。
- App 日志明确、成对输出“原图地址”和“压缩地址”。
- 列表继续加载后，日志中的唯一原图地址从 67 增加到 114。
- 已发现地址均来自 `cdn-mctchildfoliocn.childfolio.net`，以 `.jpeg` 结尾且不带查询参数。
- 一个原图地址的 HEAD 请求返回 HTTP 200；单字节 Range 请求返回 HTTP 206；内容类型为 `image/jpeg`。
- Android UI 树暴露列表和大图资源 ID，后续可以使用 UI Automator 滚动，而无需视觉识别。
- 正式路线不依赖 Root、私有缓存或 Android 的“保存到内存卡”功能。

## MVP 包含

- 连接当前正在运行的唯一 MuMu 设备。
- 锁定包名 `com.childfolio.family` 的当前进程。
- 从该 PID 的现有 logcat 中解析“原图地址”。
- 严格校验 URL scheme、host、port 和路径。
- 去重并确定性选择三个不同候选。
- 顺序下载三个 JPEG 到隔离测试目录。
- 验证 HTTP、内容类型、文件魔数、文件大小、像素尺寸和 SHA-256。
- 生成不含完整 URL、照片内容和 EXIF 的脱敏报告。
- 用户人工打开样本确认内容与画质。

## MVP 不包含

- 不滚动列表，不触发新页加载。
- 不点击照片、下载、分享或保存按钮。
- 不使用视觉识别或 UI Automator 派发输入。
- 不读取 App 私有数据或缓存。
- 不清空 logcat，不修改权限、AppOps、登录状态或 Root 状态。
- 不下载压缩图或视频。
- 不导入 Mac“照片”App。
- 不做全量、并发、断点续传、人物识别或 URL 枚举。

## 前置条件

- MuMu 已启动且只有一个目标设备处于 running。
- 鑫时光集已登录目标账号，进程仍然存活。
- 当前进程日志中至少有三个不同“原图地址”。
- 用户显式使用执行参数授权本次三个样本下载。

条件不满足时只报告缺失条件并停止，不自动打开 App、滚动列表或改变模拟器状态。

## 组件

### 设备发现器

通过 MuMu 自带 `mumutool info` 获得设备状态和 ADB 端口。只接受唯一、状态为 running 的现有设备。

### 日志采集器

通过 MuMu 自带 ADB 查询目标 PID，读取该 PID 的现有 logcat。不清空日志，也不启动持续后台监听。

### URL 解析器

仅提取严格匹配“原图地址::https://...”的日志行，并执行：

- scheme 必须为 `https`；
- hostname 必须精确等于 `cdn-mctchildfoliocn.childfolio.net`；
- 端口必须为空或 443；
- 不允许用户名、密码或 fragment；
- 路径必须以 `.jpeg` 结尾；
- 按完整 URL 去重；
- 持久化标识只使用 URL SHA-256，不保存完整 URL。

压缩地址和其他日志 URL 全部忽略。

### 样本下载器

每个样本使用 HTTPS GET 顺序下载：

1. 不携带 App Cookie、Token或额外请求头；
2. 设置连接超时、总超时和单文件大小上限；
3. 限制重定向次数，并对每一跳重新校验允许列表；
4. 先写入 `.part`；
5. 验证通过后原子改名为 `.jpeg`；
6. 失败不得覆盖完成文件；
7. 网络瞬时失败最多有限重试一次。

### 验证器

要求最终 HTTP 200、`image/jpeg`、JPEG 魔数与解码成功、合理文件大小和像素尺寸，并计算 SHA-256。三个样本内容哈希必须互不重复，否则继续选择下一个候选。

验证器不得输出 EXIF、地点、时间、设备信息或照片预览。

## 输出

运行产物位于：

```text
build/direct-original-smoke/<run-id>/
```

目录权限仅允许当前用户访问。文件名不包含 URL 路径、账号或个人信息：

```text
sample-01-<url-hash-prefix>.jpeg
sample-02-<url-hash-prefix>.jpeg
sample-03-<url-hash-prefix>.jpeg
```

`report.json` 只记录运行时间、包名/版本/PID、URL 哈希、HTTP 状态、内容类型、文件名、字节数、像素尺寸、文件哈希和脱敏错误类型。

## 隐私与安全

- 完整 URL 视为敏感凭据，只在进程内存中短暂存在。
- stdout、stderr、UI、报告和文件名不得出现完整 URL。
- `build/` 与图片扩展名由 `.gitignore` 排除。
- 不把 URL、照片、哈希或元数据上传到第三方。
- 只处理官方 App 在当前账号会话中主动输出的地址。
- 不推导、扫描或枚举其他资源地址。
- 重定向不得离开允许列表域名。
- 失败时删除 `.part`；验证完成的样本保留给用户人工检查。

## 运行界面

MVP 使用独立命令行 smoke 工具。默认 dry-run，只报告设备、包/PID、合格唯一候选数量和计划输出目录，不发起完整 GET。

只有显式 `--execute` 才下载三个完整样本。

## 测试与验收

### 离线测试

- 混合原图、压缩图和无关 URL 时只提取原图。
- 拒绝 HTTP、错误域名、子域欺骗、非 443 端口、凭据、fragment 和非 JPEG 路径。
- 完整 URL 不出现在输出、报告、文件名或错误中。
- URL 去重、内容去重和重定向逐跳校验。
- 覆盖超时、大小限制、非 JPEG、截断、磁盘错误和 `.part` 清理。
- dry-run 和无 `--execute` 均不能产生 JPEG。
- 网络测试只使用本地服务器和合成 JPEG。

### 现场验收

1. dry-run 找到唯一设备、目标 PID和至少三个候选，不产生图片。
2. 显式执行后恰好得到三个验证通过的 JPEG 和一份脱敏报告。
3. 三个文件均可由 macOS 正常打开。
4. 用户人工确认样本属于当前账号且画质为原图。
5. Git 状态不包含样本、完整 URL 或报告。
